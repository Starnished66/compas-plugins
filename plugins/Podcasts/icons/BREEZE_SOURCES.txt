Rendered from the 22px symbolic SVGs and filled with the player's native
submenu gradient (gold, cyan, mint, coral or purple), at each file's
original size.

  manage.png         <- actions/22/configure-symbolic.svg (cyan)
  play.png           <- actions/22/media-playback-start-symbolic.svg (mint)
  refresh.png        <- actions/22/view-refresh-symbolic.svg (cyan)
  remove.png         <- actions/22/edit-delete-symbolic.svg (coral)
  search.png         <- actions/22/edit-find-symbolic.svg (gold)
  show.png           <- devices/22/audio-input-microphone-symbolic.svg (purple)
